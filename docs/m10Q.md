# u-blox M10Q Best Practices Configuration Guide

## 1. Configuration Persistence (Critical)
The M10Q RAM is volatile. Settings must be saved to Battery-Backed RAM (BBR) to survive power cycles.

- **Apply to RAM + BBR**: When using `UBX-CFG-VALSET`, set the `layer` parameter to `3` (RAM + BBR).
- **Warning**: A hardware reset (`RESET_N` pin) clears RAM but preserves BBR.
- **Command Example**:

Layer: 0x03 (RAM + BBR) Transaction: 0x00


## 2. GNSS Constellation Selection
Balance accuracy vs. power consumption based on application.

### High Accuracy (Drones/Robotics)
- **Enable**: GPS, Galileo, GLONASS, BeiDou B1C. 
- **Note**: BeiDou B1I cannot be used simultaneously with B1C or GLONASS L1OF. 
- **SBAS**: Enable for <2m accuracy (WAAS, EGNOS).

### Power Saving (Asset Trackers)
- **Enable**: GPS + Galileo only. 
- **Disable**: GLONASS, BeiDou, SBAS.
- **Benefit**: Reduces current from ~37 mW to ~25 mW. 

## 3. Dynamic Platform Model
Prevents position "jumping" or lag by matching the navigation filter to physical movement.

| Application | Setting (`CFG-NAVSPG-DYNMODEL`) | Value |
| :--- | :--- | :--- |
| **Drones / High Dynamics** | Airborne <2g | 7 |
| **Automotive** | Automotive | 4 |
| **Pedestrian / Wearables** | Pedestrian | 3 |
| **Stationary / Timing** | Stationary | 2 |

- **Static Hold**: Enable (`CFG-NAVSPG-STAT HOLD`) for applications that stop frequently. Freezes position when speed < 8 m/s to prevent drift.

## 4. Signal Integrity & Interference
- **Super-S Technology**: Keep **Enabled** (`CFG-NAVSPG-SIGATTCOMP` = Automatic).  Improves urban canyon performance.
- *Exception*: Disable if using Protection Levels (mutually exclusive).
- **Interference Detection**: Enable ITFM (`CFG-ITFM-ENABLE` = 1) to mitigate RF interference (e.g., video transmitters).
- **Elevation Mask**: Set minimum elevation (e.g., 10°) via `CFG-NAVSPG-CIVMIN` to ignore multipath-prone low-angle satellites.

## 5. Power Save Mode (PSM)
For battery-operated devices not requiring continuous updates. 

- **Mode**: Use **Cyclic Tracking (PSMCT)** for periodic fixes (0.5s – 10s). 
- **Configuration Keys**:
- `CFG-PM-OPERATEMODE`: Enable PSM.
- `CFG-PM-POSUPDATEPERIOD`: Time between fixes.
- `CFG-PM-ONTIME`: Duration to track.
- **Constraints**:
- **Disable** BeiDou B1C and SBAS (unsupported in sleep states).
- Save config to **BBR** (RAM is cleared in PSM Off states). 

## 6. UART & Output Rates
- **Baud Rate**: Increase to **115200** or **230400** for update rates >1Hz to prevent buffer overflows.
- **Message Filtering**: Disable unused NMEA messages (GSV, GST).
- **Keep**: `UBX-NAV-PVT` or `NMEA-GGA`/`RMC`.
- **Navigation Rate**: Default is 1Hz. For drones, set `CFG-RATE-MEAS` to 200ms (5Hz) or 100ms (10Hz).
- *Note*: High rates (>5Hz) may require OTP configuration for high CPU clock. 

## 7. Quick Configuration Checklist (Drone/High-Performance)
1. **DynModel**: Airborne <2g (7).
2. **Constellations**: GPS, Galileo, GLONASS, BeiDou B1C. 
3. **Super-S**: Enabled.
4. **UART Baud**: 115200+.
5. **Update Rate**: 5Hz or 10Hz.
6. **Persistence**: Write to RAM + BBR (Layer 3). 

## 8. Example `UBX-CFG-VALSET` Sequence (Pseudo-code)
```c
// Set Dynamic Model to Airborne <2g
Key: 0x20110021 (CFG-NAVSPG-DYNMODEL)
Value: 7
Layer: 3 (RAM + BBR)

// Set Measurement Rate to 5Hz (200ms)
Key: 0x30210001 (CFG-RATE-MEAS)
Value: 200
Layer: 3

// Enable Super-S (Automatic)
Key: 0x20110026 (CFG-NAVSPG-SIGATTCOMP)
Value: 1
Layer: 3

// Save Configuration
Send UBX-CFG-VALSET with above keys
Wait for UBX-ACK-ACK
